# Contributing

Contributions are welcome.

This is a small, single-contributor project, so the contribution process is intentionally simple.

## Reporting Issues

Use the project issue tracker for:

- Bug reports
- Feature requests
- Security issues
- General improvements

Please include enough information to understand and reproduce the issue where applicable.

## Pull Requests

Pull requests are welcome.

Before submitting a pull request:

- Base your changes on the latest `main` branch.
- Keep changes focused and reasonably small.
- Follow the existing code style.
- Add or update tests where appropriate.
- Make sure existing tests still pass.

Please include a short description of what the change does and why it is useful.

## Development

The `main` branch contains the currently supported version of the project.

For development setup, build instructions, and project-specific commands, see the project README.

## Code of Conduct

Please keep discussions constructive and respectful.
